# Memory Functions

## `memory_write`

```luau
function memory_write(type: string, address: number, value: any)
```

Writes a value to a specific memory address.

- `type`: The type of value to write (e.g., `"float"`, `"double"`, `"int"`).
- `address`: The memory address to write to.
- `value`: The value to write.
