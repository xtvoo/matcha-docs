# Matcha Documentation

Welcome to the documentation for the Matcha LuaVM.

Matcha is a LuaVM that attempts to emulate Roblox engine functions externally, making it undetected but lacking direct access to internal Roblox API functions.

## Getting Started

To understand how the LuaVM works, you first need to understand the basics of Lua(U). For that, visit [lua.org](https://www.lua.org).
